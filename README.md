# Neon Reflex

Neon Reflex is a fast-paced synthwave arcade game built with HTML, CSS, and JavaScript.

Move through a neon world, avoid incoming hazards, collect glowing energy cores, and try to achieve the highest possible score while a randomized music playlist plays in the background.

The game has a retro-futuristic visual style inspired by classic arcade games and synthwave aesthetics, featuring neon colors, a glowing sunset, mountains, stars, and a moving perspective grid.

Neon Reflex runs directly in a web browser and does not require installation.

All songs come from Pixabay.
